# Usada Lens Admin

Dasbor admin dan kurator BRIN dibangun penuh dengan Flutter, bukan web. Folder ini dikerjakan belakangan dan diisi project Flutter milik Frontend 2 dengan susunan lib yang sama seperti `frontend/mobile/` dan token tema yang sama dari Figma Variables.

Aturan arsitektur ada di `docs/ARSITEKTUR.md`. Seluruh endpoint `/admin/*` pada `openapi.yaml` hanya dapat diakses peran `curator`.
